# zaius-dev

Un instalador de consola que deja un proyecto listo para trabajar con la IA,
de uno de dos tipos:

- **Una web**, con Astro: páginas, contenido y buscadores.
- **Una app**, con React y Vite: usuarios, datos y gestión.

Cada proyecto llega con TypeScript, una arquitectura, una nomenclatura, unas
reglas de código, unas comprobaciones y un proceso de trabajo con la IA en el
que la persona decide cada paso.

**En construcción.** Cómo se instala y se usa llegará con la primera versión.
Lo que deja en un proyecto está en [AGENTS.md](./AGENTS.md).
